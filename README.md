# San-Ysidro-waits-

Un cartoon sobre la fila peatonal de San Ysidro, contado desde el lado que ya está acostumbrado a esperar.
A cartoon about the San Ysidro pedestrian line, told from the side that's already used to waiting.

## Personaje principal / Lead character

**Jesús "Chuy" Ibarra Rocha** — 11 años. Nacido en San Ysidro, criado en Tijuana. Dos ciudadanías, una abuela, un perro que solo ladra en rojo.
